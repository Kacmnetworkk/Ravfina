# Quickstart & Organization Architecture

Every Ravfina tenant runs inside an isolated organization slug under `/app/[org]` (for example `/app/vanguard-robotics` or `/app/northstar-cloud`). Each organization owns segregated currency wallets, card spend guardrails, credit facilities, and RBAC team memberships.

## Default Environment URLs

- **Marketing & Pricing**: `/` and `/pricing`
- **Signed-In Workspace**: `/app/vanguard-robotics` (`?autostart=1` resolves automatically)
- **Developer Hub (REST + MCP + OpenAPI + Billing)**: `/api`

<Callout tone="amber" title="Role Hierarchy">
Supported server-side roles include Owner, FinanceAdmin, Controller, Maker, Checker, and Viewer. Maker/Checker separation blocks self-approval on pending money movements.
</Callout>
